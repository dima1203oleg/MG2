# MARSHGO — SECURITY AUDIT REPORT

**Дата аудиту:** 2026-10-24  
**Контур перевірки:** `MarshGO-Server`, `MarshGO-Site`, `MarshGO-Admin`, `MarshGO-Partner`, `MarshGO-iOS`

---

## 1. Перевірені механізми безпеки

1. **Автентифікація та сесії (`/api/v1/auth/*`)**:
   - Підтвердження телефону через одноразові OTP-коди з обмеженням спроб та часу життя.
   - Підтримка примусового завершення всіх сесій користувача (`POST /api/v1/auth/logout-all`) та негайного відкликання сесій при блокуванні акаунта модератором (`suspend_account`).
2. **Авторизація та RBAC (`passenger`, `driver`, `partner`, `moderator`, `admin`)**:
   - Адміністративні ендпоінти (`/api/v1/admin/*`) захищені перевіркою ролей `admin` / `moderator`.
   - Партнерські B2B-ендпоінти (`/api/v1/partner/*`) ізольовані за організацією перевізника.
   - Публікація поїздки водієм вимагає верифікованого авто з державним номером та завантаженим фото (`vehicleUsable`).
3. **Криптографічний захист посадкових квитків `MarshPass`**:
   - QR-токени підписуються алгоритмом `HMAC-SHA256` (`TICKET_SIGNING_SECRET`), що унеможливлює підробку квитка або повторне використання чужого токена на посадці.
4. **Приватність геолокації (`Rendezvous` та `Navigation`)**:
   - Обмін живими GPS-координатами між водієм і пасажиром у `Rendezvous` вмикається **лише у часовому вікні перед посадкою та виключно за взаємною згодою обох учасників** (`currentParticipantConsent`).
   - Будь-який учасник може миттєво відкликати згоду на передачу GPS одразу з екрана поїздки або карти зустрічі.
   - Точні транзитні координати зустрічі не публікуються у відкритому доступі.
5. **Захист даних користувача (GDPR / Право на експорт і видалення)**:
   - Реалізовано повний експорт власних даних у JSON (`GET /api/v1/users/me/export`) без витоку сторонніх записів.
   - Реалізовано двофазний процес видалення акаунта з періодом охолодження (`cooling_off`) та можливістю скасування.
6. **Відсутність секретів у клієнтському коді**:
   - Жодні приватні ключі (`JWT_SECRET`, `TICKET_SIGNING_SECRET`, `DATABASE_URL`, `REDIS_URL`) не експортуються у клієнтський бандл `VITE_*`.
