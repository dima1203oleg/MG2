# MARSHGO — ARCHITECTURE AUDIT

**Дата аудиту:** 2026-10-24  
**Статус архітектури:** Єдина канонічна архітектура 5+1 (без паралельних серверів або дубльованих клієнтів)

---

## 1. Системна топологія

1. **Клієнтський рівень (`MarshGO-Site` + `MarshGO-iOS`)**:
   - SPA/PWA на React 19 + TypeScript + Tailwind CSS 4 + MapLibre GL JS (`6.15.0`).
   - Канонічна нижня навігація з 5 елементів: `Головна | Пошук | + | Поїздки | Профіль`. Повідомлення та сповіщення винесені у верхній хедер.
   - Динамічна hero-зона головного екрана (`HomeHero.tsx`): преміальний банер попуток за відсутності поїздок, `MarshPass` за наявності однієї активної поїздки, та візуальний каскад із перегортанням при декількох активних квитках. Жодних дубльованих полів пошуку на головному екрані.
   - Канонічна сітка 12 видів транспорту 4×3 (`TransportTypesPanel.tsx`):
     - Ряд 1: `Попутка | Маршрутка | Автобус | Таксі`
     - Ряд 2: `Трамвай | Тролейбус | Метро | Поїзд`
     - Ряд 3: `Велосипед | Самокат | Каршеринг | Трансфер`
     - «Усі» працює як дія вибору всіх доступних видів, «Пішки» є параметром планувальника, а метро у Львові чесно вимкнене на рівні міського каталогу провайдерів.

2. **Маршрутний і картографічний рівень (`CanonicalRouteLip` + `JourneySegmentStrip` + MapLibre)**:
   - `CanonicalRouteLip`: загальний час ліворуч, вертикальний розділювач, чесна загальна ціна (`—` при `UNKNOWN`, без фейкових `0 ₴`), бейдж режиму (`Оптимальний`, `Найшвидший`, `Найдешевший`), кількість пересадок, кнопка збереження та розгортання.
   - `JourneySegmentStrip`: пропорційна кольорова шкала тривалості сегментів + горизонтальні плитки сегментів (іконка зліва, назва справа, знизу жирним `час · ціна`, горизонтальний скрол зі стрілкою при `> 4` сегментах, повне підсвічування активного прямокутного блоку кольором вибраного транспорту `--segment-active-color`).
   - **6 канонічних екранів навігації × 2 теми (12 станів)** у `JourneyRouteMapScreen.tsx`:
     1. `Full Route Details` (Повні деталі маршруту)
     2. `All Route Results` (Усі варіанти маршрутів)
     3. `Half-Expanded Route` (Напіврозгорнутий маршрут)
     4. `Compact Route Map` (Компактна карта маршруту)
     5. `Live Bus Focus` (Живий автобус і зупинки)
     6. `Live Rideshare Pickup` (Попутка і посадка / Rendezvous)
   - MapLibre керується жестами без кнопок `+` і `-`, підтримує перемикання `Схема ↔ Супутник`, `3D`, `Шари` та автоматичний `fitBounds` з урахуванням висоти bottom sheet.

3. **Серверний рівень (`MarshGO-Server` / `server.ts`)**:
   - Мультимодальний планувальник (multi-label RAPTOR + OSRM дорожня геометрія + Pareto-фільтрація для режимів `BALANCED`, `FASTEST`, `CHEAPEST`).
   - Правило чесної ціни: маршрут із невідомою ціною (`UNKNOWN`) ніколи не позначається як `CHEAPEST`.
   - Двошаровий кеш `SmartCache` (L1 in-memory + L2 Redis-сумісний шар із дедуплікацією одночасних запитів `inflight` для захисту від cache stampede) та динамічним радіусом геопошуку (400 м → 800 м → 1500 м у місті; 5 км → 15 км → 30 км для міжміських попуток).
   - 55 SQL-міграцій PostgreSQL/PostGIS (`001_initial_schema.sql` … `055_partner_platform_foundation.sql`) з індексами `GIST`.
   - WebSocket `/api/v1/realtime` для живого чату, GPS-телеметрії та сесій зустрічі `Rendezvous`.
   - Підписані `HMAC-SHA256` токени посадкових квитків `MarshPass`.
   - Чесна комісійна модель: `0%` комісії для приватних попуток (`MARSHGO Community`, `platform_fee_minor = 0`) та окремий B2B-контур для комерційних партнерів (`8%`).
